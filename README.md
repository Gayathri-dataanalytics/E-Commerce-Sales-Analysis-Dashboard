 E-Commerce-Sales-Analysis-Dashboard
Interactive E-Commerce Sales Analysis Dashboard using Microsoft Excel.
Project Overview:

This project is an E-Commerce Sales Analysis Dashboard created using Microsoft Excel to analyze sales performance and customer purchasing patterns.
The dashboard transforms raw e-commerce transaction data into meaningful insights using Pivot Tables, Pivot Charts, data aggregation, and interactive dashboard elements.
The analysis helps understand overall sales performance, product performance, customer activity, payment preferences, order status, and sales trends.

Project Objectives:

The main objectives of this project are:
Analyze overall e-commerce sales performance
Identify top-performing products and categories
Understand monthly sales trends
Analyze customer purchasing behavior
Compare sales performance across different cities
Analyze different payment methods
Track order status such as Delivered, Returned, and Cancelled
Calculate important business KPIs
Build an interactive and easy-to-understand dashboard
